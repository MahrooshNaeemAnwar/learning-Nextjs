## 📚 Kya Seekha Aaj?

### Flexbox Classes:
| Class | Meaning |
|-------|---------|
| `flex` | Flex container |
| `flex-row` | Horizontal layout |
| `flex-col` | Vertical layout |
| `justify-center` | Center horizontally |
| `justify-between` | Space between |
| `items-center` | Center vertically |
| `gap-4` | Space between items |
| `flex-wrap` | Wrap items |

### Grid Classes:
| Class | Meaning |
|-------|---------|
| `grid` | Grid container |
| `grid-cols-3` | 3 columns |
| `col-span-2` | Span 2 columns |
| `gap-4` | Space between items |

### Decision Rule:
```
1D Layout (row/column) → FLEXBOX
2D Layout (rows + columns) → GRID
```

## 💡 Key Learnings

### Flexbox vs Grid:
```
Flexbox = 1D (row ya column)
Grid = 2D (rows + columns)

Navbar → Flexbox (justify-between)
Card Grid → Grid (grid-cols-3)
Sidebar → Flexbox (flex row)
Centered → Flexbox (justify-center + items-center)
```

### Common Patterns:
```
1. Navbar: flex justify-between items-center
2. Card Grid: grid grid-cols-1 md:grid-cols-3 gap-6
3. Sidebar: flex min-h-screen (sidebar + main)
4. Centered: flex items-center justify-center
```
