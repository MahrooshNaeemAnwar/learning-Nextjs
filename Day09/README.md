## 📚 Kya Seekha Aaj?

### Breakpoints:
| Prefix | Min Width | Device |
|--------|-----------|--------|
| (base) | 0px | Mobile |
| `sm:` | 640px | Large Mobile |
| `md:` | 768px | Tablet |
| `lg:` | 1024px | Laptop |
| `xl:` | 1280px | Desktop |

### Mobile-First Rule:
```
1. Pehle base classes likho (mobile)
2. Phir md: lagao (tablet)
3. Phir lg: lagao (desktop)
```

### Common Patterns:
```
Responsive Text: text-xl md:text-3xl lg:text-5xl
Responsive Grid: grid-cols-1 md:grid-cols-2 lg:grid-cols-3
Hide/Show: hidden md:block / block md:hidden
```
