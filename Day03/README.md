## 💡 Key Learnings

### Tailwind CSS Rules:
```
1. Utility-first - Direct classes use karo
2. Mobile-first - Pehle mobile, phir responsive
3. Hover states - hover: prefix use karo
4. Responsive - md: lg: xl: prefixes
```

### Common Mistakes:
```
❌ Dynamic classes nahi chalte: className={`text-${size}`}
✅ Complete classes likho: className={size === 'large' ? 'text-xl' : 'text-sm'}
```

### Color System:
```
blue-50 (lightest) → blue-950 (darkest)
500 = Main color
Light backgrounds: 100, 200
Dark text: 800, 900
```
