## 📚 Kya Seekha Aaj?

### Suspense Syntax:
```tsx
import { Suspense } from 'react';

<Suspense fallback={<Loading />}>
  <AsyncComponent />
</Suspense>
```

### Key Points:
```
✅ Server Components can be async
✅ Suspense wraps async components
✅ Fallback shows while loading
✅ Multiple Suspense = parallel loading
```
